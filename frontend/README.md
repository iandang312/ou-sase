# OU SASE Frontend

Next.js (App Router, TypeScript) frontend for the OU SASE platform. Currently just
a placeholder page — UI work comes later.

## Requirements

- Node 22 (see `.nvmrc`)

## Setup

```bash
npm install
```

## Run the dev server

```bash
npm run dev
```

Open http://localhost:3000.

## Test & lint

```bash
npm run test
npm run lint
```
